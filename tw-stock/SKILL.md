# 台股與美股怎麼買

## 給使用者看的樣子（最重要）

使用者看不懂太多統計數字。主畫面與回覆都只回答這些問題：

1. 這檔的期望值如何（用「買 10 萬平均約賺多少」這種說法）
2. 短線多少進合理
3. 長線多少進合理
4. 不推薦買的就直接說不建議買
5. 已經持有的話，這檔目前偏強、方向不明還是偏弱，要不要賣

美股和台股格式一致。R²、信賴區間、Kelly、IC 這些術語不放在主畫面和回覆裡；需要交代的限制，改用白話講（例如「可信度低」）。詳細數據只放在儀表板的「大盤細節」。

原則：數字來自歷史行情的條件分佈，不寫主觀目標價。沒有根據就說不建議買，不要硬給價格。

## 每次的流程

1. 大盤：`python ~/.claude/skills/tw-market-outlook/scripts/market_scan.py --out <scratchpad>/scan.json`，引擎對不上證交所收盤會中止，要查原因，不可略過。
2. 台股類股：`scripts/sector_scan.py --out <scratchpad>/sector.json`，產生 `sector_rows.json` 與 `sector_bt.json`。
3. 美股：`scripts/us_ai_scan.py --out <scratchpad>/us_ai.json`，產生 `us_ai_rows.json` 與 `us_ai_bt.json`。
   自選股：`scripts/custom_scan.py --out <scratchpad>/custom.json`，名單在 `custom_stocks.json`，產生 `custom_rows.json`，資料集 `custom_stocks`。
4. 搜尋事件：財報與財測、雲端資本支出、聯準會與 CPI 日程、中東與兩岸、關稅與出口管制、地震颱風、MSCI。事實都要附來源。
5. **更新儀表板（每次都要）**：https://claude.ai/artifact/T2b1dUe2YyDNAgBpauNvKm
   - `scripts/export_dashboard.py <scan.json> <資料夾>` 匯出大盤資料。
   - 用 Artifact `asset: true` 上傳後，更新 `datasets/<id>` 的 `url` 與 `updated`。
   - 個股資料集：`sector_stocks`、`us_ai_stocks`；持有建議驗證：`hold_backtest`（台股與美股的 `_bt.json` 合併成一個陣列）。
6. 回覆：先講結論，再列使用者問的股票或類別，最後給儀表板連結。

步驟 1 到 3 可用背景執行，全部約 10 分鐘以上。

## 建議怎麼算

- **類別**：台股用官方產業別，市值 = 官方收盤 × 已發行股數，每類前五大，排名必須現算。記憶體與美股成分是人工清單。
- **合理進場價**：從現價往下試 0、0.5、1、1.5、2、3 倍日均波動，取第一個「成交至少 30 次、買進後期望值 90% 區間下緣大於 0，且下一檔也成立或成交太少」的價位。找不到就是不建議買。
- **短線**：持有 20 日，2.5 倍 ATR 停損。**長線**：持有 60 日，不設停損。
- **最多投入**：min(1% ÷ 單筆最差損失, ¼ Kelly, 10%)，只有方法通過樣本外驗證且優於自身歷史才全額，否則減半。
- **已持有**（與買進成本無關）：60 日區間上緣 < 0 為脫手；60 日平均 < 0 或 20 日區間上緣 < 0 為減碼；60 日區間下緣 > 0 為續抱；其餘為可抱不加碼。回測在 `hold_backtest`。

  **2026-10-30 的驗證顯示賣出訊號不準**：台股、美股被判減碼的股票，之後 60 日都比續抱好。所以內部的「減碼／脫手」對使用者只能說「偏弱，想降低持股時優先賣」，不可說「建議賣出」。除非回測顯示偏弱確實跑輸偏強，否則維持這個說法。
- **可信度**：樣本外 R² 大於 0 為中，否則為低。

## 判讀規則

- 美股第 D 日影響台股 D+1；日韓港中與台股同時反應，沒有領先性。
- 美股影響在開盤就反映完了，追開盤沒有額外優勢。
- 財報後的盤前、盤後跌幅不在收盤價裡，回覆時要一起講。
- 六大類因子（`scripts/factors.py`）目前只當風險提示；只有擴充模型的樣本外 R² 轉正且高於原模型，才可影響建議。
- 法人、期貨、新聞情緒沒有預測力證據前，不可說它們會決定漲跌。
- 用今天的大公司回看歷史有倖存者偏誤；個股與 0050 共用同一份風險預算，不可相加。
- 美股以美元計、不含匯率，成本以複委託單邊 0.25% 估算，沒有官方收盤可核對。
- 這是歷史統計，不是保證，也不是個人化投資建議。
